# 程序与《X 新人浏览互动 SOP》的对应表

> 依据：`C:\Users\Aron\Downloads\X新人浏览互动SOP.md`（534 行）

## 一、SOP 条款 → 程序行为

| SOP | 原文要点 | 程序里的实现 |
|---|---|---|
| 0.1 | 先理解再动作，没读懂不赞不评 | 所有动作前先过 `sop.should_skip` / `quality_score`；扫读阶段只读不评 |
| 0.2 | 阅读、点赞、评论、收藏、关注、转帖是**独立选择**，不追求数量与固定间隔 | 点赞/评论/收藏各自独立判定（各有概率），允许「只赞不评」「只看不互动」；不再有「先赞再评」链条 |
| 0.3 | 官方没公布「详情页权重更高/停留多少秒更安全」 | 代码里没有任何「必须停留 N 秒」「必须点进详情再赞」的逻辑，注释里也写明了这点 |
| 0.4 | 时间盒是自我管理，不是安全阈值 | `behavior.session_minutes` 默认 25 分钟，到点停；不做「刷满 X 分钟」的承诺 |
| 0.5 | 不编造亲历、不承诺互关、不批量复制短句 | 评论校验 `BANNED_COMMENT_PATTERNS` + `FABRICATION_PATTERNS`；**删除了搜「互关/新朋友」回关的逻辑** |
| 2.2 | 三层阅读：扫读 → 展开 → 核实 | 扫读靠 `should_skip`；展开由 `should_expand`（长帖/引用/回复必展开，其余 25%）；核实不自动化（程序只提示需人工核对） |
| 2.3 | 浏览顺序：通知 → 关注时间线 → 推荐 → 搜索 | `x_session` 固定按 通知 → Following → For You 走 |
| 2.4 | 关注谁看内容质量，不看粉丝数 | 关注走 `sop.quality_score` 排序，完全不读粉丝数 |
| 2.5 | 到点就停 | 时间盒到点立即 break，不做「再回几条」 |
| 3.1/3.2 | 读懂并认可才赞；不为任务、不为曝光、不为比例 | `should_like` 按内容质量调整概率，低质量帖不赞 |
| 4.1 | 评论三部分：锚定 + 贡献 + 边界 | LLM prompt 重写为这三段；生成后强制校验 |
| 4.1 | 检查句：这句话是不是只有看过这条原帖才能写出来 | `validate_comment` 用 bigram 命中（非泛词）+ 禁用词 + 编造检查；不合格退回重写一次，仍不合格就不发 |
| 4.7 | 禁止批量同义短评 / 无关推广 / 承诺互关 / 编造亲历 | 全部写成硬校验，命中即拒 |
| 4.8 | 自己的通知优先处理；纯表情不必追问 | 通知放在会话最前；`notification_needs_reply` 过滤纯表情/纯 @ |
| 5.1 | 关注前看简介、近期多篇、回复质量，并能说出理由 | `should_follow(profile, recent_tweets, reason)` 三项都查；理由写进 store |
| 5.2 | 不要批量关注再批量取关 | 每会话最多关注 `follow_per_session`（默认 1）；取关保留但需手动执行、数量受参数控制 |
| 6 | 收藏留给以后会用到的内容，分类消化 | 新增 `bookmark()` 动作，只在「工具/方法/教程/限制」类内容上低概率收藏 |
| 7 | 转帖/引用需逐条判断，引用要加自己的话 | 自动转帖默认关闭（`allow_repost=False`），程序不做自动转帖 |
| 15 | 通知 → 关注时间线/列表 → 推荐 → 定向搜索 | 同上，会话固定顺序 |

## 二、行为设置里的默认值（可在 UI 改）

| 参数 | 默认 | 说明 |
|---|---|---|
| 时间盒 session_minutes | 25 分钟 | SOP 2.5 建议 20~30 |
| 展开详情 expand_prob | 0.25 | 长帖/引用/回复仍强制展开 |
| 点赞 like_prob | 0.35 | 质量越高实际概率越高 |
| 评论 comment_prob | 0.20 | 且必须能通过「只有看过原帖才写得出来」校验 |
| 收藏 bookmark_prob | 0.05 | 只对可复用内容 |
| 每次关注 follow_per_session | 1 | 慢慢加 |
| 允许转帖 allow_repost | 关闭 | SOP 要求人工判断 |
| 搜互关找人 search_mutual_follow | 关闭 | SOP 0.5/4.7 禁止互动交换 |
| 回复间隔 reply_gap_min/max | 60~240 秒 | SOP 不追求固定间隔，故放宽 |
| 打字间隔 typing_ms | 150 ms/字 | 用户指定 |

## 三、和之前版本的差异（重要）

1. **不再搜索「互关 / 新朋友 / 朋友」关键词去回关**：SOP 明确把互动交换列为禁止行为。
   关注改为「从时间线里挑内容靠谱的人 → 点开主页看简介和近期几条 → 能说出理由才关注」。
2. **不再「每条都点进去 → 点赞 → 评论」**：改为三层阅读 + 三个动作各自独立，允许什么都不做。
3. **评论从「生成一句」升级为「生成 + 硬校验 + 不合格重写/放弃」**，杜绝放哪都成立的短评。
4. **新增收藏动作**，并且与点赞分开判断。
5. **定时任务默认关闭**（SOP 结尾：不需要为此创建定时自动任务）——功能保留，需要时在 UI 里手动开启。
