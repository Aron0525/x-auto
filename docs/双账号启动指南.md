# 两个号各自启动（独立浏览器配置文件）

> 目的：测试号 @johnJackyoi0f 和正式号 @4395Aron 各用一个**独立的浏览器配置文件**，
> cookies、插件数据、历史记录全部隔离。避免两个号被平台关联。
>
> 插件源码目录（两个配置文件都装这一份）：`E:\DSH\tui\extension`

---

## 为什么不能用同一个浏览器开两个标签页

插件里查找 x.com 标签页用的是 `chrome.tabs.query()[0]` —— 永远取**第一个**匹配的标签页。
同一个浏览器开两个号，插件分不清该操作哪个，而且两个号的
「已回过哪些帖 / 已关注谁 / 跳过自己帖子」这些数据会混在一起，
正式号会用测试号的记录去判断，直接出错。

所以：**一个配置文件 = 一个号**。

---

## 一次性准备：建两个配置文件目录

目录随便放，建议放在非系统盘：

```
E:\edge-test      ← 测试号 john Jacky  @johnJackyoi0f
E:\edge-official  ← 正式号 Jack        @4395Aron
```

不用手动创建，下面第一次启动时 Edge 会自动建好。

---

## 启动测试号（独立窗口）

**方法一：命令行（推荐，存成快捷方式）**

1. 在桌面右键 → 新建 → 快捷方式
2. 「请键入对象的位置」填：

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --user-data-dir="E:\edge-test"
```

> Edge 装在别处的话，把路径换成实际的。找不到就打开 `edge://version`，
> 看「可执行文件路径」那一行。

3. 下一步 → 命名「X-测试号」→ 完成
4. 双击启动

**方法二：纯浏览器操作**

1. 打开 Edge
2. 点右上角头像 → 添加 → 不使用同步，添加新配置文件
3. 命名「测试号」→ 完成后会开一个独立窗口

---

## 启动正式号（独立窗口）

同样方法，只是目录和名字不同：

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --user-data-dir="E:\edge-official"
```

存成快捷方式，命名「X-正式号」。

## 每个配置文件里要做的事（各做一遍）

### 1. 装插件

1. 地址栏输入 `edge://extensions`
2. 打开左下角「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选择目录：`E:\DSH\tui\extension`
5. 装好后把「X Auto SOP」固定到工具栏（拼图图标 → 图钉）

> 两个配置文件装的是**同一份代码**，改了代码两边都生效，
> 但要各自点一次「重新加载」才更新。

### 2. 登录对应的号

- 测试配置文件 → 登录 @johnJackyoi0f
- 正式配置文件 → 登录 @4395Aron

**别在同一个配置文件里切换账号** —— 登出再登入会留下痕迹，也不算真正隔离。

### 3. 配置插件（点工具栏图标打开控制台）

按顺序填：

| 位置 | 填什么 |
|---|---|
| **我的账号** | 两个号都填：`johnJackyoi0f, 4395Aron`（防止自己回自己） |
| **API 配置** | 各自的 DeepSeek Key → 点「保存 API 配置」 |
| **每日上限** | 见下方「正式号建议参数」 |
| **关注 / 发现** | 关注间隔 60~180 秒、每小时 8 次 |

`我的账号` 两个号都填两个人名是有意为之：**即使某个号误操作到对方页面，也不会去动它**。

### 4. 打开 x.com

确认插件识别到账号：控制台顶部应该显示 `@johnJackyoi0f` 或 `@4395Aron`。
显示「账号未识别」就刷新一次页面。

## 正式号建议参数（比测试号保守）

新号期最怕被标记，正式号前期宁可慢：

| 参数 | 测试号 | 正式号（前期） | 说明 |

| 会话分钟 | 30 | **20** | 一轮别太久 |

| 每轮关注≤ | 5 | **3** | |
| 关注间隔 | 60~180 秒 | **120~300 秒** | 放宽一倍 |
| 每小时关注≤ | 8 | **5** | |
| 日赞上限 | 60 | **30** | |
| 日评上限 | 20 | **10** | |

跑满 2~3 天没有异常（不弹验证、不掉赞、不提示 rate limit），再逐步调到测试号的量。

## 日常操作顺序

```
1. 双击「X-测试号」快捷方式 → 用测试号验证新功能
2. 确认日志正常（没报错、行为符合预期）
3. 双击「X-正式号」快捷方式 → 跑正式号
```

**永远先在测试号验证，再上正式号。** 两个窗口可以同时开，
它们是不同的浏览器进程，互不干扰。

## 常见问题

**Q：两个窗口能同时跑吗？**
能。不同 `--user-data-dir` 就是完全独立的进程和存储。但建议错开时间跑，
同一 IP 同时两个号高频操作，关联风险会上升。

**Q：正式号能只在一个配置文件里换账号登录吗？**
不建议。登出登录会留痕，且插件存储里的「已回复/已关注」记录会混在一起。

**Q：改了代码怎么更新？**
两个配置文件各去 `edge://extensions` 点一次「重新加载」。
已开着的 x.com 标签页不用管——插件有自动注入兜底。

**Q：插件数据存在哪？**
每个配置文件自己的 `chrome.storage.local`，互不可见。
测试号的记录不会污染正式号。

**Q：想彻底重置某个号的数据？**
该配置文件里打开控制台 → 浏览器开发者工具 → Application → Storage →
清空 Extension Storage，或者在 `edge://extensions` 移除插件再重装。
