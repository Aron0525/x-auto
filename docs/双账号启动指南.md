# 两个号各自启动（完全独立）

> 每个号一套：**独立的浏览器配置目录 + 独立的插件代码目录**。
> 改了测试号的代码，不会影响正式号；反之亦然。

---

## 目录结构（已建好）

```
E:\edge-test\                    ← 测试号 john Jacky  @johnJackyoi0f 的浏览器配置
E:\edge-test\extension\          ← 测试号的插件代码（独立一份）
E:\edge-official\                ← 正式号 Jack        @4395Aron  的浏览器配置
E:\edge-official\extension\      ← 正式号的插件代码（独立一份）

E:\DSH\tui\extension\            ← 开发主目录（源码在这里改）
```

三份代码的含义：

| 目录 | 用途 |
|---|---|
| `E:\DSH\tui\extension` | **开发主目录**。改代码在这里改，改完提交 git |
| `E:\edge-test\extension` | 测试号运行用的副本 |
| `E:\edge-official\extension` | 正式号运行用的副本 |

**为什么副本要分开**：两个浏览器配置文件各自加载自己的插件目录。
如果都指向同一个目录，等于两个号跑同一份代码——一旦你在测试号上试新功能改坏了，
正式号也会跟着坏。分开之后，测试号可以先跑新版几天，稳定了再同步给正式号。

## 桌面快捷方式（已建好）

| 快捷方式 | 参数 |
|---|---|
| **X-测试号** | `msedge.exe --user-data-dir="E:\edge-test"` |
| **X-正式号** | `msedge.exe --user-data-dir="E:\edge-official"` |

双击即可。两个窗口是**完全独立的浏览器进程**，cookies、插件数据、历史全隔离。

## 首次安装（每个配置文件各做一遍）

### 1. 装插件

1. 双击对应快捷方式打开窗口
2. 地址栏输入 `edge://extensions`
3. 打开左下角「开发人员模式」
4. 点「加载解压缩的扩展」

**注意选对目录：**

- 测试号窗口 → 选 `E:\edge-test\extension`
- 正式号窗口 → 选 `E:\edge-official\extension`

5. 装好后把「X Auto SOP」固定到工具栏（拼图图标 → 图钉）

### 2. 登录对应账号

- 测试号窗口 → 登录 @johnJackyoi0f
- 正式号窗口 → 登录 @4395Aron

**别在同一个窗口里切换账号。**

### 3. 配置插件（点工具栏图标）

| 位置 | 填什么 |
|---|---|
| **我的账号** | 两个号都填：`johnJackyoi0f, 4395Aron` |
| **API 配置** | 各自的 DeepSeek Key → 点「保存 API 配置」 |
| **关注 / 发现** | 按下方参数表设置 |

`我的账号` 填两个人名是有意为之：即使某操作误落到对方页面，也不会去动它。

### 4. 验证

打开 x.com，控制台顶部应显示当前账号名（`@johnJackyoi0f` / `@4395Aron`）。
显示「账号未识别」就刷新一次页面。

## 代码更新流程

改代码 → 同步到对应目录 → 重载插件。

### 开发时的标准流程

```
1. 改 E:\DSH\tui\extension\ 里的代码
2. git 提交
3. 先把新版同步到测试号目录，验证
4. 稳定后再同步到正式号目录
```

### 同步命令

用现成的脚本（`E:\DSH\tui\tools\sync.bat`）：

```
sync.bat test       只同步到测试号
sync.bat official   只同步到正式号
sync.bat all        两个都同步（确认测试号验证过再用）
```

在文件管理器里双击 `sync.bat` 等于 `sync.bat test`（默认只同步测试号）。
也可以在 PowerShell 里跑：

```powershell
& "E:\DSH\tui\tools\sync.bat" test
```

### 同步后必须重载

去对应窗口的 `edge://extensions`，点「X Auto SOP」卡片上的**重新加载**按钮。

> 已开着的 x.com 标签页不用刷新——插件有自动注入兜底，会自己补上。

## 正式号建议参数（前期保守）

新号期最怕被标记，正式号前期宁可慢：

| 参数 | 测试号 | 正式号前期 | 说明 |
|---|---|---|---|
| 会话分钟 | 30 | **20** | 一轮别太久 |
| 速度系数 | 1.5 | **1.5~1.8** | 越慢越像真人 |

| 每轮关注≤ | 5 | **3** | |
| 关注间隔 | 60~180 秒 | **120~300 秒** | 放宽一倍 |
| 每小时关注≤ | 8 | **5** | |
| 日赞上限 | 60 | **30** | |
| 日评上限 | 20 | **10** | |
| 日关注上限 | 25 | **15** | |

跑满 2~3 天没有异常（不弹验证、不掉赞、不提示 rate limit），再逐步调到测试号的量。

```
1. 双击「X-测试号」→ 验证新功能
2. 看日志正常（不报错、行为符合预期）
```

## 常见问题

**Q：两个窗口能同时跑吗？**
能，是完全独立的进程和存储。但建议错开时间——同一 IP 同时两个号高频操作，
关联风险会上升。

**Q：改了主目录代码，正式号为什么不自动变？**
这是故意的。正式号用的是 `E:\edge-official\extension` 里的独立副本，
必须你显式同步过去才会更新。这样测试号上的实验代码不会污染正式号。

**Q：插件数据存在哪？**
每个配置目录下的浏览器存储里，互不可见。
`E:\edge-test` 和 `E:\edge-official` 各自保存自己的「已回复/已关注/留档」记录。

**Q：想彻底重置某个号？**
删掉整个配置目录（比如 `E:\edge-test`），重新双击快捷方式会建全新的。
注意：**删了插件代码也会没**，要重新复制一份进去再装。

**Q：能只重置插件数据、保留登录状态吗？**
可以。在窗口里打开控制台的开发者工具 → Application → Storage →
清空 Extension Storage，或者在 `edge://extensions` 移除插件再重装（选同一目录）。
